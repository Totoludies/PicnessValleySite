Bienvenue dans le **Picness Wiki**, le guide de Picness Valley.

Picness Valley est un jeu de village en 3D. Quatre habitants arrivent dans une vallée sans rien : à vous de les guider pour récolter, construire et passer l'hiver au chaud.

:::note[Jeu en développement]
Picness Valley change presque chaque jour. Ce wiki suit la **version 0.97**. Les nouveautés sont listées dans les [notes de version](/notes/).
:::

- [Bien démarrer](/wiki/bien-demarrer/) : vos premières minutes dans la vallée.
- [Commandes](/wiki/commandes/) : souris, clavier, caméra.

## Le village
- [Habitants](/wiki/habitants/) : leurs besoins et comment ils choisissent quoi faire.

- [Bâtiments](/wiki/batiments/) : tout ce que vous pouvez construire.

- [Saisons](/wiki/saisons/) : une année en quatre minutes.
